# 오송 유치원·어린이집 교사 채용 공고 수집기

공고를 모아 `out/jobs.json`과 목록 페이지 `out/index.html`을 만듭니다.

| 출처 | 방식 | 범위 |
|---|---|---|
| 충북교육청 기간제교사 인력풀 (mpool) | 게시판 HTML 읽기 | 지역 '청주' + 유치원 글 → 본문에서 '오송' 확인, 접수 마감일 추출 |
| 충북교육청 학교구인정보 | 게시판 HTML 읽기 | 유치원 글 → 본문에서 '오송' 확인 |
| 충북육아종합지원센터 인력뱅크 | 게시판 HTML 읽기 | 소재지 '흥덕구' → 상세에서 '오송' 확인 |
| ↳ 어린이집 간호사·간호조무사 | 같은 게시판 | 직종·제목에 '간호'가 있으면 **청주시 전체**에서 수집 (자리가 드물어서) |
| 고용24 | 오픈API (인증키 필요) | 키워드 보육교사·유치원교사·어린이집·어린이집 간호조무사, 흥덕구. 병원 간호조무사 공고는 제외 |

본문·주소에 '오송'이나 '만수초'가 있으면 **오송**, 아니면 **인근 청주**로 분류합니다. 단어는 `crawler.py` 맨 위 `OSONG_KEYWORDS`에서 바꿀 수 있습니다.

## 1. 내 컴퓨터에서 실행

```bash
pip install -r requirements.txt
python crawler.py            # 게시판마다 5페이지
python crawler.py --pages 10
```

`out/index.html`을 브라우저로 열면 됩니다. 실행할 때마다 지난 결과와 합쳐서, 게시판에서 밀려난 공고도 60일 동안 기록에 남습니다.

## 2. 처음 실행할 때 확인할 것

이 스크립트는 사이트에 직접 접속해 보지 못한 상태로 작성했습니다. 표 구조를 실제 게시판 목록 형태에 맞춰 읽도록 했지만, 처음 한 번은 결과를 확인해 주세요.

- 어떤 출처가 `목록 표를 찾지 못함` 또는 `0건`이면:
  `python crawler.py --only childcare --pages 1 --debug` 를 실행하면 받은 HTML이 `out/debug/`에 저장됩니다. 그 파일을 보면 원인을 알 수 있습니다.
- **육아종합지원센터 페이지 넘기기:** 페이지 번호 파라미터 이름을 확인하지 못해 `offset`과 `pageIndex`를 같이 보냅니다. 2페이지부터 같은 목록이 반복되면 자동으로 멈추니, 1페이지만 읽히는 경우 브라우저에서 2페이지로 넘길 때 주소창의 파라미터를 보고 `crawl_childcare()`의 `params`를 고쳐 주세요.
- **고용24:** 인증키를 받은 뒤 API 명세서의 호출 주소·파라미터·지역코드가 `WORK24_URL`, `WORK24_PARAMS`와 같은지 확인하세요. 다르면 그 값만 고치면 됩니다.

### 고용24 인증키

고용24 → 고객센터 → OPEN-API → 서비스 소개 및 신청에서 채용정보 API를 신청합니다. 받은 키는 실행 전에 환경변수로 넣습니다.

```bash
# macOS / Linux
export WORK24_KEY=발급받은키
# Windows PowerShell
$env:WORK24_KEY="발급받은키"
```

키가 없으면 고용24만 건너뛰고 나머지는 그대로 수집합니다.

## 3. 매일 자동 실행 + 링크로 보기 (GitHub)

1. 이 폴더를 GitHub 저장소로 올립니다.
2. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿉니다.
3. (선택) **Settings → Secrets and variables → Actions**에 `WORK24_KEY`를 추가합니다.
4. **Actions** 탭에서 '오송 채용공고 수집'을 한 번 수동 실행(Run workflow)합니다.

이후 매일 아침 7시쯤 자동으로 수집하고 `https://<아이디>.github.io/<저장소>/` 주소에 목록 페이지가 갱신됩니다.

> 공개 저장소면 페이지도 공개됩니다. 공고 정보만 담기지만, 원치 않으면 비공개 저장소를 쓰세요. (비공개 저장소의 Pages는 유료 요금제에서만 됩니다.)

## 사용 시 주의

- 요청 사이에 1.2초씩 쉬도록 되어 있습니다(`DELAY`). 기관 서버 부담을 줄이기 위해 더 줄이지 마세요.
- 하루 한두 번 정도 개인 용도로 쓰는 것을 전제로 만들었습니다.
